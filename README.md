# **Solids 1.0 – Web User Guide**

This project contains the interactive web interface for the **Solids 1.0 User Guide**, a frontend-based documentation platform for the Solids crystal-structure prediction package.  
It includes dynamic navigation, smart search, code highlighting, and a responsive UI.

---

## 📑 Main Features 🚀

### ✔️ Interactive Sidebar Navigation
- Menu with expandable sections and subsections.
- Clicking a subsection scrolls **directly** to the corresponding paragraph (no jumping up/down).
- Exclusive section system: only one main section is visible at a time.

### ✔️ Search Bar with History
- Automatic text highlighting within the content.
- Search term memory stored using `localStorage`.
- Smart autocomplete and navigation through matches.

### ✔️ Modern Animations and Design
- Smooth entry animations powered by **AOS (Animate On Scroll)**.
- Consistent visual theme across the entire guide.
- Fully responsive UI for both desktop and mobile devices.

### ✔️ Python Code Highlighting
- Integrated **Prism.js** for syntax highlighting.
- Functional “Copy” button in every code block.

### ✔️ Mobile Navigation Support
- Hamburger menu for small screens.
- Dynamic layout adjustments based on screen width.

---


## 🧩 Technologies Used

### **Frontend**
- **HTML5** – Content structure  
- **CSS3** – Styling, responsive design, animations  
- **Vanilla JavaScript** – Navigation logic, search system, dynamic scrolling  

### **External Libraries**
- **Prism.js** – Syntax highlighting  
- **AOS.js** – Scroll animations  
- **Ionicons** – Icon set
